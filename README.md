# Digital Calculator Using ALU

## Project Overview
This project implements a digital calculator using Verilog HDL. It uses an Arithmetic Logic Unit (ALU) to perform arithmetic and logical operations.

## Technologies Used
- Verilog HDL
- EDA Playground
- Xcelium Simulator

## Features
- Arithmetic operations
- Logical operations
- Verilog-based digital design
- Testbench-based simulation and verification

## Project Files
- `design.v` – Main calculator design
- `testbench.v` – Testbench for simulation

## Simulation
The project was simulated using EDA Playground.
